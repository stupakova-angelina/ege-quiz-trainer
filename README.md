# 🎯 Консольный тренажер для подготовки к ЕГЭ
Простая и удобная программа на языке Python для быстрой проверки знаний по школьным предметам. Проект создан в рамках подготовки к экзаменам в 11 классе, чтобы повторять теорию, исторические даты и формулы прямо в терминале, не отвлекаясь на браузер.

## ✨ Основные возможности

* **Случайный порядок вопросов:** при каждом запуске программа перемешивает задания, чтобы исключить механическое заучивание ответов по порядку.
* **Умная проверка ввода:** скрипт не обращает внимания на регистр букв и случайные пробелы в начале или конце ответа.
* **Работа над ошибками:** в конце тестирования программа показывает итоговый балл и выводит список всех вопросов, в которых были допущены ошибки, вместе с правильными ответами.
* **Легкое редактирование базы:** добавить свои вопросы по любому предмету (информатика, история, физика, русский язык) можно за пару секунд прямо в коде.

## 💻 Пример работы

```text
--- ТРЕНАЖЕР ДЛЯ ПОДГОТОВКИ К ЕГЭ ---

Вопрос 1 из 3:
Сколько бит в 1 килобайте? (введи число)
Твой ответ: 8192
Верно!

Вопрос 2 из 3:
В каком году произошло Крещение Руси?
Твой ответ: 980
Неверно. Правильный ответ: 988

--- ИТОГИ ТРЕНИРОВКИ ---
Правильных ответов: 1 из 2

Темы, которые нужно повторить:
- В каком году произошло Крещение Руси? -> Ответ: 988
```


## ⚙️ Требования

* **Операционная система:** Windows, macOS или Linux
* **Версия Python:** Python 3.6 и выше
* **Внешние библиотеки:** Не требуются (используется только стандартный модуль `random`)

## 🚀 Как запустить проект

1. Убедитесь, что на вашем компьютере установлен Python 3.
2. Скачайте файл `trainer.py` из этого репозитория (или клонируйте репозиторий через консоль):
   ```bash
   git clone https://github.com
   ```
3. Откройте терминал (или командную строку) в папке с файлом и запустите скрипт:
   ```bash
   python trainer.py
   ```

## 📝 Как добавить свои вопросы

Откройте файл 'trainer.py` в любом текстовом редакторе и добавьте новый блок в список `questions` по следующему шаблону:

```python
{
    "question": "Текст вашего вопроса",
    "answer": "Правильный ответ"
},
```
